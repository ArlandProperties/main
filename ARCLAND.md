# Arcland Properties Inc

A responsive property management workspace with portfolio summaries, property editing, tenant records, payment tracking, maintenance requests, activity history, and CSV portfolio exports.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static web server. No installation or build step is required.

## Data

The app starts with sample properties, tenants, and maintenance requests. Changes are stored in the current browser using localStorage (`arcland-v1`). Data is not synchronized between users or devices. Export report downloads property records as CSV.

## Assets

Fonts load from Google Fonts and property photos load from Unsplash; these require internet access.

## Hosting

The root `index.html` can be deployed to a static host. GitHub Pages has not been enabled by this upload. The existing private Sites deployment is separate from this repository; GitHub commits do not automatically update it.
