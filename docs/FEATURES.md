# 200 module capabilities

This is an explicit count of 20 modules × 10 module-level capabilities. The same nine record workflows are supported independently in each module; the tenth is a domain action. Shared authentication, roles, reports, calendar, backups, payment reversals, and team tools are additional.

Archive operations preserve records and validate active references. Posted payments are retained; active leases must be ended before archiving. Actions only run from supported statuses. CSV exports respect the current search/status/archive filters.
