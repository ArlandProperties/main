# 300 additional module capabilities

These are 15 new workflows independently available in each of the 20 administrator/staff modules. Together with the original 200 module capabilities, the directory has 500 entries. This is a count of module-level capabilities, not 300 unrelated integrations. Tenant and agent access remains limited by their server-enforced roles and assignments.

Shared tools: server-persisted personal views/bookmarks, transactional bulk actions (up to 100 records), immutable public application receipt metadata, internal comments, and per-record audit history. Financial and linked-record safeguards apply to bulk operations just as they do to individual edits. Posted payments and paid invoices remain protected.
