# 700 record-workspace capabilities

This expansion adds 35 workflows independently to each of the 20 company staff modules. The count is 700 module-level capabilities and the full catalog totals 1,200 (200 original + 300 advanced-module + 700 record-workspace). Shared implementation supports each module; this is not a claim of 700 unrelated integrations.

Record workspaces are internal company tools. Administrators and managers edit them; viewers have read access and personal follows. Agents and tenants cannot access company record workspaces. Existing role-scoped dashboards remain available to them. Follow-up dates do not create scheduled automation. Updates are in-app only. Reviews and completeness checks do not make legal, financial, or property-safety decisions.
